## Питання

Чи може ML-модель зменшити похибку зашумленої квантової схеми, передбачаючи поправку `delta` до
виміряного значення? І наскільки це краще за звичайний необроблений результат.

## Підхід

1. Згенерувати квантові схеми, змоделювати їх із шумом і без — зберегти дані й параметри.
2. Розділити на train/validation/test так, щоб варіанти однієї схеми не потрапляли в різні частини.
3. Порівняти прості моделі (baseline), оцінити похибку (MAE/RMSE/R²).
4. Перевірити на даних реального квантового пристрою.

## Стан (25 жовтня 2026)

- **Дані.** Основний синтетичний датасет готовий: [`data/`](data/README.md) — 1800 прикладів, train/validation/test зафіксовано. Два додаткові, значно більші датасети: [`data/raw/`](data/raw/README.md) (через Git LFS) — тепер теж проаналізовані (нижче).
- **Моделі на основному датасеті.** [`notebooks/eda_baseline_models.ipynb`](notebooks/eda_baseline_models.ipynb) — 6 моделей (Dummy/Linear/Ridge/Random Forest/XGBoost/невелика нейромережа). Random Forest і XGBoost явно кращі за лінійні моделі й за відсутність корекції (MAE 0.062 → 0.033); нейромережа на цьому обсязі даних переваги не дає.
- **Моделі на датасетах Василя.** [`notebooks/single_qubit_eda_models.ipynb`](notebooks/single_qubit_eda_models.ipynb) і [`notebooks/multiqubit_eda_models.ipynb`](notebooks/multiqubit_eda_models.ipynb) — та сама лінійка моделей, свій поділ train/validation/test за `circuit_id`. Результат інший і змістовний: жодна модель тут не покращує прогноз — для цих датасетів статистичний шум вимірювання (shot noise) порівнянний або більший за систематичну похибку, яку можна було б вивчити. Разом із цим нарешті підтверджена залежність похибки від кількості `shots`, яку на основному датасеті перевірити було неможливо.
- **Реальне залізо IBM.** Перевірка зроблена: [`results/real_device/`](results/real_device/README.md). Модель, навчена лише на симуляції, покращує результат на реальному пристрої на ~14% (24 тестові схеми).
- **Ще не зроблено:** порівняння з ZNE/Haiqu, розширення перевірки на реальному пристрої, можлива зміна протоколу збору даних Василя (усереднення повторів, щоб зменшити shot noise).
