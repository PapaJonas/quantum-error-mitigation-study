# Machine learning for quantum error mitigation

Курсовий дослідницький проєкт з дисципліни «Штучний інтелект» Українського католицького університету. Команда: Данило Куриляк і Василь Сольчаник. Менторка: Марта Сумик.

[Подана пропозиція проєкту (PDF)](docs/proposal.pdf) — первинний документ від 20 вересня 2026 року. Цей README описує поточний стан роботи; пропозиція збережена без змін.

## Дослідницьке питання

Чи може модель машинного навчання зменшити похибку результату зашумленої квантової схеми, передбачаючи поправку до виміряного значення? Якими будуть точність і час застосування такої поправки порівняно з початковим результатом та обраним базовим методом?

## Запланований підхід

1. Створити набір квантових схем і змоделювати їх виконання з шумом та без шуму. Вихідні значення і параметри генерації даних мають бути збережені для відтворення експерименту.
2. Розділити приклади на навчальну, перевірочну й тестову частини до вибору моделі. Порядок розділення та склад тестового набору зафіксувати в протоколі експерименту.
3. Порівняти просту модель з іншими моделями, запропонованими в PDF. Оцінити похибку виправленого результату та час застосування на однаковому тестовому наборі.
4. За наявності доступу провести окрему перевірку на даних реального квантового пристрою. Результати симуляції та пристрою подавати окремо.

Основна запланована міра точності — середня абсолютна похибка між виправленим і еталонним значеннями. Перевага методу не припускається наперед: її потрібно підтвердити вимірюваннями.

## Стан на 19 жовтня 2026 року

Проведено [перший симуляційний експеримент із дзеркальними схемами](results/README.md) та [зібрано синтетичний набір із 1800 прикладів для регресії](data/README.md). Еталонні значення, зашумлені вимірювання, цільова поправка, характеристики схем і фіксований поділ на навчальну, перевірочну та тестову частини збережені разом з кодом генерації. Даних з реального пристрою, навчених моделей та оцінювання методів виправлення похибки поки немає.

Наступний етап — навчити простий baseline і порівняти його на недоторканому тесті з початковим зашумленим значенням. У пропозиції згадано ZNE та метод Haiqu; їхню роль в остаточному порівнянні ще слід узгодити. Запланована частка даних з реального пристрою не є підтвердженням їх доступності. Умови використання даних IBM визначаються окремо від ліцензії програмного забезпечення Qiskit.
