# Machine learning for quantum error mitigation

Курсовий дослідницький проєкт з дисципліни «Штучний інтелект» Українського католицького університету.
Команда: Данило Куриляк і Василь Сольчаник. Менторка: Марта Сумик.

[Пропозиція проєкту (PDF)](docs/proposal.pdf) — первинний документ, 20 вересня 2026.

## Питання

Чи може ML-модель зменшити похибку зашумленої квантової схеми, передбачаючи поправку `delta` до
виміряного значення? І наскільки це краще за звичайний необроблений результат.

## Підхід

1. Згенерувати квантові схеми, змоделювати їх із шумом і без — зберегти дані й параметри.
2. Розділити на train/validation/test так, щоб варіанти однієї схеми не потрапляли в різні частини.
3. Порівняти прості моделі (baseline), оцінити похибку (MAE/RMSE/R²).
4. Перевірити на даних реального квантового пристрою.

## Стан (25 жовтня 2026)

- **Дані.** Основний синтетичний датасет готовий: [`data/`](data/README.md) — 1800 прикладів, train/validation/test зафіксовано. Два додаткові, значно більші датасети: [`data/raw/`](data/raw/README.md) (через Git LFS) — поки без поділу на вибірки, ще не аналізувались.
- **EDA + baseline-моделі.** Зроблено в [`notebooks/eda_baseline_models.ipynb`](notebooks/eda_baseline_models.ipynb). Random Forest явно кращий за лінійні моделі й за відсутність корекції (MAE 0.062 → 0.033 на тесті).
- **Реальне залізо IBM.** Перша перевірка зроблена: [`results/real_device/`](results/real_device/README.md). Модель, навчена лише на симуляції, покращує результат на реальному пристрої на ~14%.
- **Ще не зроблено:** складніші моделі (градієнтний бустинг, нейромережа), порівняння з ZNE/Haiqu, аналіз великих датасетів з `data/raw/`.
